# 🏠 Home Automation System with Arduino

A home automation project developed to control lights and doors through a mobile application, connecting hardware and software through wireless communication.

---

## 🚀 Overview

This project was created during a technology course in 2024 with the objective of building a functional smart home prototype.

The system connected a mobile application to physical components controlled by Arduino, allowing different parts of the house to be controlled remotely.

---

## ⚙️ Features

* 💡 Remote light control
* 🚪 Opening and closing doors through the mobile app
* 📱 Mobile interface developed for the project
* 📡 Wireless communication using Bluetooth / Wi-Fi

---

## 🛠️ Technologies Used

* **Arduino** – hardware control
* **PictoBlox** – block-based programming
* **Kodular** – mobile application development
* **Bluetooth / Wi-Fi** – wireless communication

---

## 📱 How It Works

The mobile application sends commands wirelessly to the Arduino.

The Arduino receives and processes these commands, controlling physical components of the prototype such as lights and door mechanisms.
